## Overview

This project is a browser extensions manager interface that allows users to view, search, filter, activate, deactivate, and remove extensions. It includes a light/dark theme switcher and saves user preferences in the browser.

## Features

- View browser extensions in a card-based layout.
- Filter extensions by All, Active, and Inactive.
- Search extensions by name.
- Toggle extensions between active and inactive states.
- Remove extensions with a confirmation modal.
- Close the confirmation modal using the Escape key or by clicking outside it.
- Switch between light and dark themes.
- Persist extension states, removals, and theme preferences using `localStorage`.
- Display a message when no extensions match the current search or filter.
- Responsive layout for different screen sizes.
