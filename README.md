# Browser Extensions Manager UI

A responsive browser extensions dashboard built using HTML, CSS, and JavaScript.

## Features
- View browser extensions
- Filter by All, Active, and Inactive
- Search extensions by name
- Toggle extension status
- Remove extensions with a confirmation modal
- Light and dark themes
- Save extension states and theme preferences using localStorage

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
